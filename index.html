How to use

Measure: capture a photo, calibrate with two points of a known distance, then tap points for length, perimeter or area.
Object Counter: type the object name (for example pencil), capture the scene, then scan. Detected objects are outlined and numbered.
Daily history: save a result once per day. The app stores the object's name, date and count in local browser storage.
Accuracy: camera perspective, overlap, shadows and object size can affect measurements and AI counting. Keep the camera steady and objects separated where possible.
Camera permission: browser camera access requires a secure context such as HTTPS on supported browsers.
